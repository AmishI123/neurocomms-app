## Design and required work

Store named follow-up drafts separately from visits and preparation. Capture the original source item and context; a reopened progress draft must not silently adopt a newer saved item. Explicit draft saving never records progress. Completing saved progress needs one write that both adds history and removes only the expected draft. Older transfer fingerprints must remain stable across the collection upgrade.

Delivered: validated record model and migration; guarded save/delete/finish operations; editor/list/Home integration; private structured backups and transfer/remapping; offline shell update; tests, walkthroughs, presentation, help, acceptance map and extracted release verification. The shared web app remains the target; native Android/iOS packaging is deferred as agreed.
