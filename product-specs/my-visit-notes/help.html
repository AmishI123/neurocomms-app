Prepare the next appointment

From Home or the after-visit screen, choose Prepare the next appointment. Pick a saved visit, then select the questions, next steps and communication requests you want. Nothing starts selected. Answered or closed items are inside a separate disclosure. Review the chosen words before creating the new appointment.

The new appointment is a temporary visit until you save it. Creating it may replace unsaved open work: read the warning and cancel to keep a backup first. Selection dialogs do not survive browser closure. Copied questions start Open and next steps start To do. Private preparation notes, answer notes and history are not copied; earlier source titles and dates stay with copied items.

Edit the new words, add concerns and use Move up or Move down to choose the question order. Moving a question resets the starting position to the first question in that order; save successfully before closing. In What helps, edit requests or uncheck Show this request. Review my appointment plan shows the exact questions, visible requests and next steps with dates/contacts. It excludes private notes, answers, history and source context. Copying, downloading and printing do not save or send the plan. The short plan is not a full recovery backup.

Where this item came from opens a read-only source view. Available wording is the current source wording, not a preserved original quotation. Private answers and history are not shown. If the source is unavailable, no other item is substituted. Original and copy change separately.

Save successfully before closing. After offline setup, saved appointments reopen offline. Full visit backups, saved-library backups and private device transfer retain normal appointment fields; full transfer can carry both source and copied visits. Different transferred versions stay separate. Choose conversation words deliberately at the appointment, then return to personal notes and after-visit review.

Save unfinished follow-up for another day

In a message or progress editor, choose Save draft on this device. First save asks before keeping private words and source context here. A progress draft also keeps its original item, including private notes and history, to detect later changes. Anyone using this browser may open saved drafts. There is no account, automatic sending or encryption.

Later edits need another explicit save. Read the draft status: saving a draft does not record progress, send a message or mark anyone contacted. Home shows a neutral saved-draft count. Open saved follow-up drafts to choose a private name; nothing reopens automatically. Saved drafts can reopen offline after app files are ready.

Save follow-up records the progress entry and removes that exact saved draft together. Failed or cancelled completion does neither. If the original item changed or disappeared, the draft stays readable but cannot overwrite newer work or be attached to another item. Keep a private backup and start a new entry deliberately from current saved work.

Discard removes the working editor, not its saved copy. Delete a saved draft from its list after confirmation. Deleting a visit does not erase independent saved drafts, which may contain earlier words. Downloaded files must be managed separately.

Download private draft backup preserves editable fields. Restoring asks for a preview and keeps a separate copy; repeated identical restores are skipped. A draft-only backup does not carry its source visits, so restored progress is not connected to a guessed local item. Full device transfer includes saved drafts with their linked source visits. Unsaved later edits are excluded unless saved first. Visit-only and preparation-only backups do not include independent saved follow-up drafts.

Draft backups are unencrypted and limited to 10 MiB. A draft name may contain up to 200 characters, a message up to 1,000,000 characters and a progress note up to 5,000. A browser may close without showing a warning: rely on confirmed successful saves or a private backup.

This remains the shared desktop/mobile web app. Native Android and iOS packaging can be considered separately when needed.

Start, continue or follow up

Home separates starting a visit, continuing work and following up. It shows saved counts, not your private wording. Choose a saved visit or preparation explicitly. The fictional example is inside Try it without using your own notes.

Home hides the visit without replacing it. Return to my open visit restores this page’s work. It does not mean the visit is saved. Read the save status before closing the page. Tools and settings contains recovery, saved-work lists, transfer, reading choices and offline setup. Returning Home closes expanded private lists.

When bringing notes, check Add chosen passages to. Opening another visit does not redirect an earlier chosen destination. Review repeats the destination before adding anything. The workspace connects questions and What helps to the chosen-word conversation preview.

Unfinished work kept only in this page

Home offers return controls for unfinished preparation, a message and a progress entry. Their wording is not shown on Home. Messages and progress drafts are not saved by closing their dialogs. Unsaved edits do not survive closing the page and are not included in device transfer. Save drafts explicitly or download them first. Progress has a Download this private progress draft action.

Starting another message or editing another progress item asks before replacing retained work. Discard actions also ask for confirmation. Saving a retained progress entry still checks its original saved item and version; newer changes or deletion are not overwritten. A failed save keeps the draft available for private download.

Deleting saved visits does not erase these separate session drafts. Discard them through their Home return controls if wanted. Downloaded files must be managed separately. After-visit review shows unfinished counts and save status; returning Home does not mark anything answered or done.

Show chosen words during a conversation

In an open visit, choose Choose words for conversation view. Select questions or requests; nothing starts selected. Edit optional request wording for this session, then preview exactly what will be shown. A request can be used without a question.

Show a request temporarily replaces the question. Return to question keeps your place. Hide message and Escape hide the words without opening private notes. Resume is deliberate. Leaving asks before showing the private workspace; take the device back first. This is not a lock: someone holding an unlocked device can deliberately leave the view.

Personal answer notes never enter this display. Showing a question does not mark it answered. Return to your personal answer note or the existing after-visit review to record progress. Changed question wording requires new choices and another preview.

The current question saves only if the visit is saved and the write succeeds. The paused and exit screens report failed, waiting or conflicting saves. Temporary conversation choices and edited requests do not survive closing the page. Before closing, return to the workspace to save or download a backup if needed. Backgrounding hides an active message when the browser delivers its visibility event; screenshots and app-switcher previews are not controlled by this app.

Move to another device

Open Move to another device, then Open device transfer. Saved visits, private follow-up history, saved preparation and results, saved requests and focus can travel in one private file. Choose whether to include current reading choices. Decide separately what to do with each unsaved visit or preparation. Downloading does not save unsaved work on this browser.

The file is unencrypted and can contain private source and answer notes. Anyone with it can read it. Keep it privately. There is no automatic sending, account, cloud recovery or syncing. File size is limited to 20 MiB.

On another browser, choose the file and review the contents. Expand each record to inspect it. Different versions stay separate; nothing is overwritten automatically. Focus and reading choices start unchecked. Notes save first; reading settings save separately. If settings fail, retry only settings without repeating the import.

Unsaved visits included in a file are kept inside separate saved preparation copies. Open transferred draft opens the copy as a temporary visit; save it as a visit only if you want. Imported preparation can be resumed separately. Opening imported work asks before replacing an unfinished local draft.

Recently removed objects and recovery history are left out. Recover anything wanted before transfer. Current preparation copies may still contain earlier words. Saved follow-up drafts are transferred; unsaved editor changes are not. Save them first or download separate private draft backups.

Repeated files and deletion

This browser keeps a file fingerprint and item identifiers, not another copy of the wording, so the same file cannot silently repeat additions or recreate notes you deleted later. This local record is not exported. Forget previously restored files removes only that record after confirmation; current notes and settings remain. Importing the old file after forgetting may bring deleted content back. Downloaded files must be managed separately.

Ten fictional transfer journeys · Detailed transfer rules

What still needs doing

Open this tool to see unfinished questions and next steps across saved visits. Unsaved drafts and results kept only in preparation are not included. Choose one focus, or leave focus empty. There is no automatic ranking or reminder.

Open an item to record Contacted, Waiting for reply, Done or No longer needed. To do reopens it; Done marks a question Answered. Dates and private notes are optional. The latest 50 events stay with each item. Changing progress through the original visit screens also adds an event.

Select items to prepare a message or call note. Titles, dates and contacts start unselected. Edit the draft and preview exactly what will be copied or downloaded. Save the draft explicitly or keep a private backup before closing; otherwise the message is temporary. The app sends nothing and never treats copying as contact.

Selected items can become a new visit. Copies start fresh without answer notes or follow-up history; they keep source titles/dates. Originals and copies change independently. A missing source is reported, not replaced with another visit. Deleting the original does not delete source context already copied elsewhere.

Full backups contain private follow-up history and copied-source context. They exclude recovery history and local focus. Preparation backups also retain these details in embedded visit copies. Keep backup files private.

Fictional full journeys · Detailed follow-up rules

Fix a mistake

Choose Fix a mistake on the main page. Review a recorded change, select the items you need, then inspect the current content and proposed result before confirming. You can recover removed questions and next steps, restore earlier wording, or remove selected additions. Nothing is selected for sharing because of recovery.

Saved recovery records can contain private notes. They remain for up to seven days, limited to the latest 100 changes. Older records may disappear sooner when that limit is reached. Expired records cannot be recovered; their stored copies are removed on the next successful write. The app cannot run cleanup while closed. You can erase recovery records now without removing current notes.

Temporary draft recovery stays only in this page until you save the visit. Saving keeps its available recovery records too. If the open saved visit has unsaved changes, protect those changes before recovering saved content. Another tab or a failed write can stop recovery without changing saved notes.

Remove to recovery keeps the saved copy within these limits. Delete permanently removes that saved object and its recovery records now. Clearing all visits also clears their recovery records. Separately kept preparations, copies inside them and downloaded files remain; handle those copies separately. This is not a promise of secure erasure from a device.

A result kept inside saved preparation can be recovered without creating a saved visit. The preview identifies that copy. Reopen its completed result afterward; the original passages are not added again.

A private-note batch can be removed while keeping later wording only when the original added text is identifiable. If it was edited or appears more than once, edit the private note directly instead of asking the app to guess.

Visit, library and preparation backups contain current content, not recovery history or removed copies. Recover needed content before downloading a backup. Shared summaries and ordinary printing do not include recovery records.

Bring existing notes

Paste notes or open a UTF-8 .txt file up to 1 MiB. Select passages and choose question, personal next step, or private note. Review the exact additions and destination before confirming. Matching text is skipped unless you deliberately keep it.

The source and unfinished choices stay only in the open page unless you choose Save this preparation on this device. After changing saved preparation, save again before leaving. Saved preparations can be resumed from the main page, including offline after app files are ready. Visit backups do not include preparation; use its separate private backup. Download private source text saves the source, not separate edits to chosen items. Clear this working area does not remove passages already added to visits or delete a saved preparation. Save the cleared state or delete the saved preparation separately.

Private preparation notes never enter a shared summary. Full visit backups do include them. The app does not interpret documents or give medical instructions.

Start a visit

Choose Prepare my visit, add your questions, and save if you want to keep them in this browser. The example is fictional. You can skip communication requests and optional dates.

During the visit, Previous and Next only move your place. Only you mark a question Answered. Your personal notes are not confirmed medical answers.

Return to unfinished preparation

Open Saved preparations and choose a name. Source text, edited choices and the intended destination return. Completed batches are not added again. Open last completed result recovers a result without repeating its passages.

Saving preparation keeps private source, selections and destination draft copies on this device. It does not separately save a visit. A result kept only in preparation can be lost if that preparation is deleted. Save the visit or download a private preparation backup first.

If a saved destination changed, review its latest content. If it was deleted, choose another destination. An older backup cannot know about later work on a different browser unless the relevant completion records are available.

Preparation backups include edited choices and retained drafts. Source-text downloads contain only the original source box. Both are unencrypted. If saving fails or tabs conflict, keep a private preparation backup before reloading.

What the saving messages mean

Temporary visit: the draft is only in this open page. Save it or download an individual backup before closing.

Saved on this device: the latest change was written to this browser. Later edits save automatically for that visit.

Changes not saved: the latest work is not safely stored. Keep the page open and download a full backup of this draft. Do not assume an older saved copy includes these changes.

Two tabs can conflict. Protect your draft with a backup before reloading saved visits. Closing a phone browser may not show a warning; save or back up first.

I cannot find my notes

Open Saved visits and recovery and clear the search field. Check the same browser and site address that you used before. Notes are not shared between different browsers, private windows, or different site addresses.

If browser data was cleared, this app has no server copy. Restore a backup file you previously downloaded. Without a saved browser copy or a backup, the app cannot recover deleted notes.

I have a backup file

Open Saved visits and recovery, then Backup files and data controls. Use Restore a backup for one visit or Restore a saved library for all saved visits and requests.

An individual restore becomes a new temporary draft. It preserves saved visits but replaces the open draft after confirmation. Back up any unsaved work first.

A library import previews additions and identical visits to skip. Conflicting copies are kept separately, not overwritten. Your open draft stays untouched. Both kinds of file can contain private notes. Imports are limited to 10 MB and the files are not encrypted.

A file is damaged or from another version

An unreadable file is rejected without changing your draft or saved library. Try the original downloaded file or another backup. Do not edit its contents just to remove an error.

Older supported backups are read by the app. A newer unsupported format needs a compatible app version; it must not be silently replaced with empty data.

Saved browser data is damaged

The app keeps unreadable stored data in place. In Backup files and data controls, Recover from damaged storage lets you download the unreadable text before an explicitly confirmed reset. That reset removes the saved collection, including preparations, saved follow-up drafts and completion records, not downloaded files. Keep the current draft backed up too.

Do not use an old app's reset merely because it cannot read newer data. Save and close old tabs, then open the latest app.

Reading and phone use

Reading choices changes size, spacing, and contrast without changing your words. Preview the choices, then save them on this device. Reset removes only these display choices. They are separate from visit backups.

Rotate the phone or scroll if a question is long. The visit controls follow the question. Optional display and note controls remain available below it. You can move freely between questions.

Install and use offline

Installation is optional. If your browser offers Install app or Add to Home Screen, use that option. Otherwise the browser page still works. Installation is not a backup.

Open once while connected and wait for Offline app files are ready. Then saved visits and these help pages work offline. A downloaded update waits for all old app tabs to close; save or back up before closing them.

For local use, serve the files on localhost. A real phone needs an HTTPS address it can reach; localhost on a phone refers to that phone, not this computer. This release does not publish a public site.

Installation support varies by browser. Technical background: MDN installation guide.
