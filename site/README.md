# PhraseBench public showcase

The static landing page links to the Phrase Studio authoring demo and the PhraseBench v3 benchmark dashboard. To preview locally from the repository root:

```bash
python3 -m http.server 8000
```

Open `http://127.0.0.1:8000/site/`. The links use repository-relative paths and are suitable for a static host that serves the repository folders.

The demos use fictional cases and browser-local state. They are not clinical tools, do not infer preferences, and do not collect research data.
