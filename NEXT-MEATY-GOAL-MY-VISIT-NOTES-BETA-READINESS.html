What this product does

My Visit Notes helps a person prepare appointment questions, choose what to show during a visit, keep personal notes separate, record what happened in their own words, save follow-up drafts and prepare the next appointment.

It does not diagnose, interpret symptoms, send information by itself or mark questions complete without the person's choice.

Data safety in simple terms

  • Visits, drafts, private notes and recovery history stay on the device.
  • There is no automatic server copy or account.
  • Only content deliberately exported, copied, shared or printed leaves the device.
  • Private notes must not appear in selected conversation or review output.
  • Use fictional data in all engineering checks.

How to test it

Web: extract the recorded archive, serve it locally and follow the browser reports.

Android: build from my-visit-notes-mobile/, use a dedicated phone or emulator, install the debug package and run the native runbook. Never clear someone else's data to make a test pass.

iPhone: on a Mac with Xcode and CocoaPods, run the iOS build script, use a clean simulator installation and repeat the same ten steps.

Record the build hash, device or simulator, operating-system version, every step result and any screenshot or log that explains a failure.

Recovery and rollback

  • Before a risky change, make a private backup and check its destination.
  • If saving fails, keep the words visible, fix storage and retry once; verify no duplicate records.
  • If a transfer looks wrong, cancel before saving and keep the original file.
  • For deletion, confirm the exact scope, delete exported copies separately and reopen to verify.
  • For an update problem, keep the old backup and restore into a separate installation before overwriting anything.
