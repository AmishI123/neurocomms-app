# Security and privacy

PhraseLab is designed for fictional examples and local processing. The browser tools do not upload submissions, use analytics, or require an account. The static demos are not hardened as a hosted service and should not be used to process personal communication logs.

If you find a security issue in the code, report it privately to the repository maintainer before publishing details. Do not include personal data in an issue or pull request. Reproduce problems with the included fictional fixtures.
