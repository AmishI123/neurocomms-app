# Reading Lab protocol sketch

## Question

Can a reading interface let a person try presentation settings and report clear, hard-to-read, or unsure without treating one response as a diagnosis or a permanent preference?

## Variables and outcomes

The simulator changes text size (14–34 px), line spacing (1.0–2.4), and line width (30–80 characters). Each event records the displayed settings and one explicit button choice. Primary descriptive outcomes are event counts by choice and differences between two exported sessions.

## Limits and next step

Fixtures and demo files verify data shape only. They contain no participant observations and do not assess reading ability, dyslexia, comprehension, fatigue, or benefit. Before any participant-facing work, have an accessibility reviewer inspect keyboard use, focus order, contrast, zoom behavior, and whether the three choices are understandable.
