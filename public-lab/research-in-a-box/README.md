# Research in a box

Students can use the fixtures and firewall to study a concrete question without collecting personal data: **does a validation-and-review boundary reduce malformed or unsupported communication-card drafts?**

Use the frozen cases, compare two pipeline configurations, preregister one primary outcome, retain all failures, and report uncertainty. Do not recruit participants or present generated cards as personalized communication without appropriate supervision and review.

Run the included classroom smoke workflow with `PYTHONPATH=.. python3 run_lab.py`. It creates deterministic fictional fixtures and scores the example submission without network access.
