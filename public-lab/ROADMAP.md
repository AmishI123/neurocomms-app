# PhraseLab public roadmap

PhraseLab is organized as one reusable platform rather than separate one-off projects.

| Project | Current artifact | Status | Next evidence needed |
|---|---|---|---|
| Communication Safety Firewall | Python package and browser demo | Working deterministic prototype | Broader adversarial fixtures and independent semantic review |
| PhraseBench Challenge | JSONL format, CLI/browser scorers, v1–v3 comparison | Working local release | External submissions and reproducible reruns |
| Adversarial Case Laboratory | Frozen cases, generator, Failure Museum | Working fictional lab | More domains and reviewer-authored cases |
| Communication Card Studio | Local-first editor and PWA shell | Working demo | Accessibility review and mentor feedback |
| Design System | Tokens, patterns, interactive examples | Working component reference | Extract reusable production components |
| Research-in-a-Box | Classroom workflow and synthetic fixtures | Working teaching kit | Instructor pilot and clearer lesson plans |
| Failure Museum | Curated lessons plus benchmark-linked records | Working public exhibit | More evidence-linked records and independent annotations |
| Semantic Evaluator | Rubric, annotation workspace, kappa tool | Working review workflow | Two or more independent reviewers on a larger sample |
| Live Atlas | Searchable static index of v1–v3 records | New public release slice | More independently reproduced runs and submitted cases |
| Red-team Case Kit | Fictional case template, examples, offline validator | New public release slice | Community-authored cases reviewed for clarity and privacy |
| Environment Lab | Sensor-free room simulator, session analyzer, protocol sketch | Working fictional simulator | Accessibility review and a pre-registered comparison design |
| Contribution Pipeline | Issue form, case studio, local runner, Atlas import | Working local workflow | First independently authored case accepted and reviewed |

The platform is ready for software demonstration, classroom experimentation, and mentor review. It is not ready to claim clinical benefit or to collect participant data. Any participant study requires an appropriate protocol, supervision, consent, privacy controls, and applicable review before recruitment.
