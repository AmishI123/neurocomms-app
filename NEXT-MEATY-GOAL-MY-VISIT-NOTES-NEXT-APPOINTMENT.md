# Prepare for the next appointment without rebuilding everything

Status: engineering delivery complete. All 271 current-source checks and the 209-file extracted-release workflow passed. Read [N1–N7 acceptance evidence](product-specs/my-visit-notes/next-appointment-acceptance-audit.md). Final package approval requires matching archive hashes in releases/manifest.json and releases/verification.json. Usefulness remains unverified.

## Outcome

Someone can choose a previous appointment, see unfinished work, deliberately select what still matters, edit and order the next appointment's questions, choose communication needs, and review a short plan. They can save it, close the browser, return offline, use it during the appointment and record what happened. The earlier visit remains unchanged.

## Full delivery

1. A clear next-appointment entry point, previous-visit choice and unfinished-item review. Nothing is selected automatically; closed items remain available only by deliberate choice.
2. Chosen questions and next steps become independent copies. Communication requests need separate selection. Private preparation notes, personal answers and history never copy into the new plan.
3. Edit copied wording, add concerns, order questions and set an optional title/date through the existing visit editor. Show what will be discussed first without ranking medical importance.
4. An exact short-plan preview with questions in order, selected communication needs and next steps. Plain-text download/copy/print do not save, send, record progress or include private notes and source context.
5. Save and reopen the plan using existing visit storage, backup and transfer. Protect unfinished work, failed saves, queued operations, changed source records and repeat confirmation. Preserve exact order and fields after a full offline browser restart and transfer.
6. Deliberate source inspection for carried items, respecting transferred source links and missing sources. The source is not silently opened or changed. Answering the new copy never answers the old item.
7. Complete the two-appointment journey through conversation and post-visit review, then identify remaining work for another visit. Include detailed plain-language requirements, twelve fictional journeys, executive/conference HTML with speaker notes, help, current-source regression tests, acceptance audit and an extracted verified release.

## Finish line

Demonstrate two connected fictional appointments with selection, editing, ordering, communication requests, exact plan review, interruption, offline return, device transfer, conversation and follow-up. No lost work, repeated additions, accidental sharing or change to the original visit. Verify failures, two tabs, source deletion, queued cancellation, keyboard, narrow/enlarged layouts, older data, all previous workflows and the final package.

This is the shared desktop/mobile web app. No participants, real appointments, medical advice, automatic scheduling/sending, accounts or native Android/iOS packaging are required. Software checks do not prove usefulness or physical-device accessibility.
